## 1. 架构落地

- 新增 `com.cloudmusictool.app.profile`：
  - `MountSpec`、`TypeResolver`、`MountResolver`、`TargetProfile`、`ProfileRegistry`、`Profile9608`；
  - 分片 `ProfileAdPv`（71 条）与 `ProfileUi`（63 条），合计 **134 个挂载点**。
- `HookKit.findClass/findMethod` 优先走 active Profile + `MountResolver`，失败回退原硬编码/DexKit 路径；
  profile 路径不重复写 HookState。
- `VersionGate` 优先用 versionCode（反射 `getLongVersionCode`）选择 Profile；未适配版本按
  `allowUnsupported` best-effort 或跳过。
- `HookState`：expected = attempted（installed + failed）；`degraded` 由 critical 挂载点失败驱动；
  `unavailable` 为 installed == 0。
- `tools/check-mounts.sh` v2：从 `app/build/profile9608.json` 生成检查项，
  断言 versionCode、类/方法存在、`method_kind IS NOT NULL`、参数/返回类型精确匹配。

## 5. 已知限制

- 只承诺 9.6.08；新增版本 = 新增 Profile 分片 + 跑 check-mounts，不承诺任意版本自动兼容。
- 部分 UI 类没有可靠的 DexKit 字符串锚点，只能精确类名匹配；类改名时需人工补 Profile。
- UI-04 仍不支持；1.2.0 的未自然触发项（AD-09/UI-10/UI-12/UI-13/UI-14）状态不变。
- Profile 解析失败会回退硬编码；回退路径的 critical 判定依赖 Profile 是否收录该坐标。
- `:play` 进程只装 AD-07，不装 ABTest/其他 UI hook，与 1.2.0 一致。
